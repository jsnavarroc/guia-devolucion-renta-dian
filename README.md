# Guía Devolución Saldo a Favor en Renta — DIAN Colombia

Guía práctica HTML estática para personas naturales que solicitan devolución del saldo a favor en su declaración de Renta ante la DIAN (Colombia), a través del portal MUISCA.

Incluye los dos errores ocultos más comunes que causan inadmisión y que ni el manual oficial de la DIAN explica:

1. El navegador (Brave/Firefox con bloqueadores oculta el botón Consultar del Formato 1220).
2. El doble significado del campo "Año" entre el XML y la pantalla "Diligenciar Solicitud Envío de Archivos".

## Contenido

- `index.html` — Página única, sin frameworks ni dependencias externas.

## Publicación

Sirve como sitio estático desde GitHub Pages, Netlify, Cloudflare Pages, o cualquier hosting de archivos.

## Aviso

Información de orientación general, no asesoría tributaria ni legal. Para situaciones específicas consulta a un contador público o abogado tributarista. No afiliada a la DIAN.
